# JS: Raamat ja raamatukogu

JavaScripti objektide ja meetodite praktiline ülesanne.

Ülesandes on:

- raamatu objekt koos kirjelduse kuvamise ja aasta muutmise meetoditega;
- raamatukogu objekt, milles on raamatute massiiv;
- meetodid raamatu lisamiseks, kõigi raamatute kuvamiseks ja koguarvu leidmiseks;
- meetod, mis arvutab pärast 2000. aastat ilmunud raamatute arvu;
- enda meetod `leiaAutoriRaamatud(autor)`, mis leiab valitud autori raamatud.

Kõik tulemused kuvatakse HTML-lehel ja brauseri konsoolis.

## Olulised failid

- `src/ulesanne.ts` — objektid, meetodid ja konsoolitulemused.
- `src/pages/Home.tsx` — tulemuste kuvamine HTML-lehel.

## Käivitamine

```bash
npm install
npm run dev
```

Seejärel ava terminalis näidatud aadress. Konsooli avamiseks vajuta brauseris F12 ja vali **Console**.
